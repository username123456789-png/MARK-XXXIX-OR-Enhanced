# Feynman Technique

**Category:** [[Meta-Learning]] · [[Study Tools]]
**Related:** [[Meta-Learning/Active Recall]] · [[Coding/Clean Code Principles]] · [[Coding/Code Complexity]]

## Four steps

1. Choose a concept.
2. Explain it to a 12-year-old using simple language.
3. Identify gaps, jargon, and places where the explanation breaks down.
4. Simplify and use an analogy, then revisit the source material.

## Core takeaway

If you cannot explain a concept simply, you probably do not understand it fully yet.

## JARVIS application

For difficult technical questions, JARVIS should offer a layered answer: one-sentence explanation, plain-language analogy, precise details, and a short self-test. It should use this method to improve explanations, not to expose private chain-of-thought.
